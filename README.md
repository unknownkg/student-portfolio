# Student Portfolio

Учебный сайт для лабораторной работы «Git и GitHub с нуля до публикации».

Автор: **Машуров Артур Геннадьевич**, группа **КС-3-24**.

## Возможности

- Адаптивная страница с разделами «Обо мне», «Учебные проекты» и контактами.
- Навигация по странице и ссылки на GitHub.
- Кнопка JavaScript с сообщением «Git и GitHub работают!».
- Поддержка клавиатурной навигации и настройки уменьшения движения.

## Технологии

HTML5, CSS3 и JavaScript. Без сборки и сторонних библиотек.

## Запуск

Откройте `index.html` в браузере.

Или запустите локальный сервер из папки проекта:

```sh
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Структура

```text
index.html   — разметка страницы
style.css    — оформление и адаптация под разные экраны
script.js    — обработчик кнопки
README.md    — описание и инструкция
.gitignore   — исключения для Git
.nojekyll    — публикация готовых статических файлов без Jekyll
```

## Практика Git

1. `main` — основная версия сайта.
2. `feature-about` — раздел «Обо мне», объединён локально командой `git merge --no-ff`.
3. `feature-projects` — раздел проектов и навигация; [Pull Request № 1](https://github.com/unknownkg/student-portfolio/pull/1).
4. При синхронизации веток разрешён конфликт в `index.html`; сохранены оба раздела.
5. Выполнены `clone`, `fetch`, `pull`, `push`, `restore` и снятие файла со staging.
6. После объединения PR ветка `feature-projects` удалена; её коммиты сохранены в истории.

## Назначение .gitignore

Исключает служебные файлы ОС, настройки редакторов, `node_modules`, журналы и
файлы `.env` с секретами. Локальные материалы сдачи (`submission/`), инструменты,
временная копия для практики clone и рабочие планы также не публикуются.
`.gitignore` не удаляет из истории файлы, уже добавленные в Git.

## Публикация

GitHub Pages: источник **Deploy from a branch**, ветка **main**, папка **/(root)**.
Обновления отправляются через `git push`.

## Проверка

Проверены кнопка JavaScript, отсутствие ошибок в консоли и отсутствие горизонтальной
прокрутки на экранах шириной 320, 390, 768 и 1440 пикселей.
